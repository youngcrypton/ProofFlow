# ProofFlow delivery roadmap

## Milestone 0 — foundation (complete)

- Narrow product thesis and trust boundary.
- Monorepo structure.
- Architecture decisions.
- MVP threat model.
- Reproducible development contract.

## Milestone 1 — reproducible skeleton

- Root package scripts and pinned toolchain.
- Shared domain package with schemas.
- Web app shell with premium trust-oriented visual language.
- API health endpoint and structured error shape.
- Contract project with compile/test command.
- CI check command.

**Exit gate:** a fresh checkout can install, typecheck, lint, test, and build without manual fixes.

## Milestone 2 — local vertical slice

- Create agreement.
- Define milestone and immutable terms.
- Deposit test funds into local vault.
- Upload/hash evidence fixture.
- Run deterministic policy with mocked AI observation.
- Create settlement intent.
- Approve and release locally.
- Show audit timeline and receipt.

**Exit gate:** one end-to-end happy path and adversarial policy/contract tests pass.

## Milestone 3 — AI evidence review

- Typed reviewer adapter.
- Evidence extraction boundary.
- Missing-evidence and uncertainty states.
- Prompt-injection fixtures.
- Human review/override with explicit reason.

**Exit gate:** malformed or adversarial AI output cannot cause release.

## Milestone 4 — X Layer testnet

- Deploy audited MVP contract to X Layer testnet.
- Network/chain ID validation.
- Wallet connection and exact transaction preview.
- Evidence root and policy version on-chain.
- Event indexing and reconciliation.

**Exit gate:** a fresh wallet can complete the demo with testnet funds and a public explorer receipt.

## Milestone 5 — judge-quality product

- Seeded demo workspace.
- Responsive dashboard and polished empty/loading/error states.
- One-click demo reset.
- Explainable policy/evidence view.
- Public demo route and submission assets.
- Performance and security review.

**Exit gate:** five-minute demo works without founder narration rescuing the product.

## Post-hackathon

- Account/team model.
- Durable database and object storage.
- Signer policy and multisig adapters.
- ERC-20 adapter after audit.
- Third-party verifiers and webhooks.
- Usage-based pricing and enterprise controls.
